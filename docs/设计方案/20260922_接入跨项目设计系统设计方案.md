**创建时间**: 2026-09-22 17:20
**背景**: 本项目的颜色、字体、字号、圆角此前全部在 `src/index.css` 里自建（暖白纸感 + 琥珀强调色），是 `D:/Projects/Personal/design-system` 之外的第二套设计语言。本次收编：色彩与字体的来源改为设计系统分发，项目不再持有任何色值。

## 1. 为什么接

不是为了"和别的项目长得一样"——设计系统的取舍是：**中性色、表面层级、边框、文字层级、语义色、交互态、对比度标准由库强制，品牌色是项目注入的插槽**。项目换得了色相和明暗，换不了体系。

自建那套的实际代价有三处：

1. **对比度无人看守**。`--color-ink-3: oklch(0.66 0.014 60)` 配 `--color-paper-2` 是否满足 WCAG AA，没有任何东西在验；设计系统有 336 组文字对比度断言 + 320 组非文字对比度断言。
2. **手搓 alpha 会长出来**。项目里已经有 `ring-accent/40`、`bg-ink/25`、`text-ink-3/70` 三处，以及一处 `oklch(0.24 0.02 55 / 0.25)` 的阴影字面量。这类衍生值换品牌色时不会跟着动。
3. **刻度是第二份定义**。`text-[13.5px]` 这类任意值绕过字号刻度，刻度整体调整时不跟随。

### 品牌色：琥珀 → teal（青绿）

原先的琥珀色族（`amber`）已于 2026-09-18 从设计系统删除——它的色相距 warning / danger 只有 10°~13°，落在语义带内，当不了品牌色。本次落 `teal`（H180），距 success 30°、距 info 70°。

界面基调因此转冷，但中性底色不变（neutral H75，仍是微暖的纸白）。

## 3. 类名映射

关键在于**同一个旧别名按用途分流**，不是机械改名——语义角色有明确的档位含义。

| 旧别名 | 用途 | 新角色 |
|---|---|---|
| `bg-paper` | 页面底 | `bg-bg` |
| `bg-paper` | 卡片 / 弹窗 / 输入控件底 | `bg-surface` |
| `bg-paper-2` | 徽章底 / 进度条槽 | `bg-surface-sunken` |
| `bg-paper-2` | hover 底 | `bg-surface-hover` |
| `text-paper` | 实心按钮上的字 | `text-on-accent` |
| `text-ink` / `-2` / `-3` | 文字三级 | `text-text` / `-secondary` / `-tertiary` |
| `border-line` | 分隔线 | `border-border-subtle` |
| `border-line` | 卡片 / 弹窗轮廓 | `border-border` |
| `border-line-2` | 输入下划线 / 复选框 / 分段控件 | `border-border-input` |
| `text-accent` | 品牌小标签文字 | `text-text-brand` |
| `ring-accent/40` | 焦点环 | `ring-focus-ring` |
| `ring-offset-paper` | 焦点环偏移底 | `ring-offset-bg` |
| `text-danger` | 错误文字 | `text-danger-text` |
| `bg-danger` + `text-paper` | 危险按钮 | `bg-danger` + `text-on-danger` |
| `bg-ink/25` | 弹窗遮罩 | `bg-scrim` |

三条判断依据：

- **文字用文字档，不用实心档**。`text-accent` 指向的 `--accent` 是 brand-9（实心档），当文字时对比度不够；`--text-brand` 是 brand-11。同理 `text-danger` → `--danger-text`。图标是非文字，`--success`（实心档，>=3:1）够用，所以成功图标保留 `text-success`。
- **手搓 alpha 一律换成角色**。`--focus-ring` / `--scrim` / `--shadow-color` 都是现成的，对比度由闸门保证。
- **分隔线与轮廓是两档**。`--border-subtle`（neutral-6）用于行间分隔，`--border`（neutral-7）用于卡片轮廓，`--border-input`（neutral-8，>=3:1）用于控件边框。

## 4. 字体

删掉手工子集 `src/assets/fonts/LXGWNeoXiHei-brand.woff2`（24KB，仅收录 17 个汉字），改用分发来的四字族（104 个文件 / 4.8MB，其中霞鹜文楷占 4.7MB）。

| 角色 | 字族 | 用法 |
|---|---|---|
| `--font-display` | Fraunces + 霞鹜文楷 | 页面主标题、弹窗标题 |
| `--font-body` | Instrument Sans + 中文系统黑体 | `body` 默认 |
| `--font-mono` | JetBrains Mono | 路径、计数、时长 |

三点实现细节：

1. **`font-mono` 类不用改**。`tokens.css` 的 `:root` 声明 `--font-mono`，是非分层样式，无条件压过 Tailwind `@layer theme` 里的同名定义，现有类名自动拿到 JetBrains Mono。
2. **`font-display` 要单给一个类**。它不在 Tailwind 的 `font-*` 命名空间里，桥接层也只映射颜色，所以 `index.css` 里写一条 `.font-display { font-family: var(--font-display); }`。
3. **字体契约：`--font-display` 只用于 `text-lg` 及以上**，更小的字号里楷体辨识度低于黑体。原先 header 的 `text-xs` 小标签用了 `font-brand`，不合规，改为走正文字族。

**运行时开销 ≈ 0**：浏览器按 `unicode-range` 惰性加载，本项目楷体只出现在十来个汉字上，97 个分片里实际读取不超过 2 个。成本只在安装包体积和构建时间。

**字体落 `src/` 而不是 `public/`**：留在 vite 模块图里换来构建期校验——字体路径写错或文件缺失在 `npm run build` 时就报错，而不是等到运行时缺字。代价是 104 个文件过 asset 管线，实测构建 7.89s，可接受。

## 5. 非颜色刻度

11 处任意值字号收敛到刻度：

```
text-[30px] → text-3xl    text-[13.5px] / text-[13px] → text-sm
text-[12.5px] / text-[12px] / text-[11.5px] / text-[11px] / text-[10.5px] / text-[10px] → text-xs
rounded-[4px] → rounded-sm
```

字号与圆角刻度在 `tokens.css` 里与 Tailwind v4 默认值**同名同值**（由设计系统第 8 条断言看守），所以 `text-sm` / `rounded-lg` 拿到的就是设计系统的值，不需要桥接。

代价是若干处字号有 0.5~1px 变化。做这件事的理由：设计系统的第 9 条断言只匹配 CSS 的 `font-size:` 声明，看不见 tsx 里的 Tailwind 任意值——不收敛就是留一处永远不会报警的漂移。

## 8. 不纳入本次范围

- **深色模式**。主题是 `scheme: 'light'`，不引入 `data-scheme` 切换。
- **组件层**（`components.css`）。Tailwind 项目不接，骨架继续来自 utility 组合。
- **布局与交互重设计**。只换色彩 / 字体 / 刻度的来源。
- **Rust 侧代码**。
